# 🎬 بوت تليجرام لتحميل الفيديوهات

بوت تليجرام بتحمّل الفيديوهات من **يوتيوب** و**فيسبوك** و**انستجرام** و**تيك توك** و **X (تويتر)** عن طريق اللينك — تختار الجودة اللي تحبها أو تحمّلها صوت MP3.

## ✨ المميزات

- 📺 يوتيوب • 👍 فيسبوك • 📸 انستجرام • 🎵 تيك توك • 🐦 X (تويتر)
- 🎬 اختيار الجودة بأزرار: 1080p / 720p / 480p
- 🎵 تحميل الصوت بصيغة MP3
- 📸 دعم صور وكاروسيل انستجرام وتيك توك (بتتبعت كألبوم)
- ⬇️ شريط تقدم حي أثناء التحميل والرفع
- 📊 إحصائيات للتحميلات والمستخدمين
- 🛡 حماية من السبام (حد أقصى للطلبات + تحميل واحد لكل مستخدم)
- 👑 أوامر أدمن: `/stats` و `/users` و `/broadcast` و `/update`

## 🤔 إزاي البوت بيشتغل؟

البوت بيظهر في تليجرام **عادي جداً** زي أي بوت — المستخدم بيبعت لينك والبوت يبعته الفيديو. لكن كود البوت نفسه لازم يشتغل على **جهاز شغال 24 ساعة**: يا جهازك الشخصي (للتجربة)، يا سيرفر مجاني (للتشغيل الدائم — الشرح تحت).

## الخطوة 1️⃣ — هات التوكن من BotFather 🔑

1. افتح تليجرام ودوّر على **@BotFather** (أو افتح الرابط: https://t.me/BotFather)
2. ابعت الأمر `/newbot`
3. اكتب **اسم** للبوت (مثلاً: `Downloader Pro`)
4. اكتب **username** بينتهي بكلمة `bot` (مثلاً: `my_pro_downloader_bot`)
5. هيبعتلك رسالة فيها **توكن** بالشكل ده:
   ```
   1234567890:AAH3xYz...توكـن...طويل
   ```
6. انسخ التوكن كامل — ده أهم حاجة في المشروع 🗝️

> 💡 عشان تجيب **الآيدي بتاعك** (للأدمن): ابعت لأي فيديو لـ @userinfobot وهيديك الـ ID.

## الخطوة 2️⃣ — التشغيل على جهازك (للتجربة) 💻

محتاج **Python 3.10+** و **ffmpeg**:

```bash
# 1) سطّب ffmpeg الأول
# Ubuntu/Debian:
sudo apt install -y ffmpeg
# macOS:
brew install ffmpeg
# Windows:
choco install ffmpeg    (أو نزّله من ffmpeg.org وضيفه للـ PATH)

# 2) في فولدر المشروع:
pip install -r requirements.txt

# 3) اعمل ملف .env (انسخه من .env.example) وحط التوكن جواه:
#    BOT_TOKEN=التوكن_بتاعك_من_BotFather

# 4) شغّل البوت:
python bot.py
```

تقدر كمان تجيب التوكن من متغير بيئة بدل الملف:
```bash
BOT_TOKEN="123456:ABC-DEF" python bot.py
```

افتح تليجرام ودوّر على البوت بتاعك وابعتله أي لينك فيديو 🎉

> 💡 مافيش أمر `git` على جهازك؟ سطّبه من git-scm.com، أو استخدم موقع GitHub وارفع الملفات يدوي (Add file ← Upload files).

### ❌ ليه مش Vercel؟

**GitHub ينفع، لكن Vercel مش مناسب للبوت ده.** فيرسيل بيشغّل دوال Serverless بتقفل تلقائياً بعد حوالي 60 ثانية، والبوت محتاج عملية شغالة طول الوقت — التحميل والرفع بياخدوا دقايق فالدالة هتتقطع في نص الشغل. فيرسيل ممتاز للمواقع والـ APIs السريعة، مش للبوتات.

**البديل اللي بيشتغل بنفس فكرة فيرسيل بالظبط** (تربط GitHub وتنزل تلقائي مع كل تعديل): 🚂 **Railway** أو 🎨 **Render** — الاتنين مجانيين وبياخدوا 5 دقايق.

### 🚂 Railway (الأسهل — كريدت مجاني من غير كارت)

1. بعد رفع المشروع على GitHub، افتح https://railway.app واعمل حساب بـ GitHub
2. **New Project ← Deploy from GitHub repo** واختار الريبو
3. من إعدادات الخدمة ← **Variables** ضيف:
   | المتغير | القيمة |
   |---|---|
   | `BOT_TOKEN` | التوكن من BotFather |
   | `ADMIN_IDS` | الآيدي بتاعك من @userinfobot |
4. Railway هيسطّب **ffmpeg تلقائياً** (بفضل ملف `nixpacks.toml`) ويشغّل البوت
5. افتح **Deployments ← View Logs** واتأكد إن مكتوب `Bot started as @...` 🚀
6. من هنا وبعدين: كل `git push` جديد هيحدّث البوت تلقائياً — نفس تجربة Vercel 🔄

### 🎨 Render (بديل مجاني)

1. ارفع الكود على GitHub
2. https://render.com ← **New ← Web Service** واربط الريبو
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python bot.py`
5. ضيف متغير البيئة `BOT_TOKEN` (و `ADMIN_IDS` اختياري)
6. ⚠️ الخطة المجانية بتُسَيِّب الخدمة بعد 15 دقيقة سكون — اعمل مراقبة مجانية على **UptimeRobot** تعمل ping كل 5 دقايق لرابط الخدمة (البوت بيرد عليها تلقائياً بمساعدة الـ keepalive المدمج)

> المشروع فيه ملفات جاهزة لكل حتة: `Procfile` + `nixpacks.toml` (Railway) • `render.yaml` (Render) • `Dockerfile` (أي استضافة بتدعم Docker بأمر واحد: `docker compose up` أو `docker run`)

## 👑 أوامر الأدمن

حط آيديك في `ADMIN_IDS` (ممكن أكتر من واحد بفاصلة):

| الأمر | الوظيفة |
|---|---|
| `/stats` | إحصائيات مفصلة + أكثر المستخدمين |
| `/users` | قايمة المستخدمين وعدد تحميلاتهم |
| `/broadcast رسالة` | إرسال رسالة لكل مستخدمين البوت |
| `/update` | تحديث yt-dlp لآخر نسخة |

## ⚙️ متغيرات البيئة (كلها اختيارية ما عدا BOT_TOKEN)

| المتغير | الافتراضي | الوظيفة |
|---|---|---|
| `BOT_TOKEN` | (مطلوب) | توكن البوت من BotFather |
| `ADMIN_IDS` | — | آيديات الأدمنز مفصولة بفاصلة |
| `MAX_FILE_MB` | 48 | أقصى حجم للملف (حد تليجرام 50) |
| `RATE_LIMIT_REQUESTS` | 5 | أقصى طلبات لكل مستخدم في النافذة |
| `RATE_LIMIT_WINDOW` | 30 | نافذة الحماية بالثواني |
| `MAX_CONCURRENT` | 3 | أقصى عدد تحميلات في نفس الوقت |
| `COOKIES_FILE` | cookies.txt | ملف كوكيز اختياري (لو موجود بيتستخدم تلقائياً) |

## 📌 ملاحظات مهمة

- **حد الـ 50MB**: تليجرام بيمنع البوتات العادية من إرسال ملفات أكبر من 50MB — لو الفيديو أكبر، البوت يقولك وتجرب جودة أقل أو MP3.
- **انستجرام/فيسبوك الخاص**: المحتوى العام بيشتغل من غير أي إعداد. المحتوى الخاص محتاج ملف `cookies.txt` حوّطه جنب كود البوت (صيغة Netscape — صدّره من إضافة كروم زي "Get cookies.txt LOCALLY" بعد تسجيل دخولك).
- **يوتيوب على السيرفرات**: ساعات يوتيوب بيطلب تحقق من السيرفرات المجانية ("Sign in to confirm you're not a bot") — لو حصل، ضيف ملف `cookies.txt` زي الفقرة اللي فوق.
- **التحديث الدوري**: المنصات بتغيّر أكوادها كل شوية — لو بطّل يحمّل، ابعت `/update` (أدمن) أو حدّث يدوي: `pip install -U yt-dlp`.
- **حقوق الملكية**: استخدم البوت لتحميل المحتوى المسموح بيه وللاستخدام الشخصي.

## 🛠 حل المشاكل الشائعة

| المشكلة | الحل |
|---|---|
| `✋ مفيش توكن!` | حط التوكن في `.env` أو متغير البيئة `BOT_TOKEN` |
| `ffmpeg not found` | سطّب ffmpeg على الجهاز/السيرفر (شوف الخطوة 2) |
| البوت مش بيرد | شغّل `python bot.py` وشوف رسايل الـ Logs |
| يوتيوب "Sign in to confirm" | ضيف ملف `cookies.txt` جنب الكود |
| انستجرام بيرفض | المحتوى العام أول بأول — للخاص ضيف كوكيز |
| فيديو أكبر من 50MB | اختار جودة أقل أو MP3 من الأزرار |
